# Portfolio

Personal project portfolio: [Block Code](https://github.com/saf-azad/BlockCode), [Metric Cage](https://github.com/saf-azad/metriccage) and [Detour](https://github.com/saf-azad/detour).

One static page, no build step. Open `index.html` or deploy the folder as-is.

```
index.html     the page
assets/        titles, screenshots, background, favicon
vercel.json    clean URLs and long-lived caching for assets
```

Type: Bayon and DM Sans via Google Fonts.
